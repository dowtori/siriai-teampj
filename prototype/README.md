# SIRIAI 어드민 — 프로토타입

운영 구글시트의 **실데이터**를 그대로 올린 어드민 프로토타입입니다.
목업 숫자는 하나도 없습니다.

기존 `siriai-admin.vercel.app` 과는 별개의 코드베이스이며, 금요일 발표에서
"실제로 이렇게 보인다"를 확인하는 용도입니다.

## 실행

```bash
npm install
npm run dev
```

기본 포트는 3210 입니다 (`.claude/launch.json` 기준).

## 데이터

`data/db.json` 은 `scripts/migrate.py` 가 만듭니다. 원본은 두 개입니다.

| 원본 | 내용 |
|---|---|
| SIRIAI 프로젝트관리 | 캠페인 68건 · 34개 항목 |
| 무신사 콘텐츠 제작 협의 인플루언서 리스트 | 진행시트 62개 탭 · 참여 기록 1,695건 |

다시 만들려면:

```bash
python scripts/migrate.py
```

> 데이터를 다시 만든 뒤에는 **개발 서버를 재시작**해야 합니다.
> `lib/db.ts` 가 파일을 한 번만 읽고 메모리에 들고 있습니다.

### 구조

`db.json` 은 앞으로 만들 PostgreSQL 스키마와 같은 모양입니다.
Supabase 로 옮길 때 테이블 정의만 쓰면 되도록 맞춰 두었습니다.

```
brands           거래처
campaigns        캠페인 (일정 · 진행 수치 · 재무)
participations   캠페인 참여 — 진행시트 한 줄이 여기 한 건
```

## 이관하면서 확인된 것

프로토타입이 화면에 그대로 드러냅니다. 숨기지 않았습니다.

**1. 시트 요약값과 행 합계가 안 맞습니다**
시트 대시보드는 총 매출 ₩322,845,000 으로 표기하지만, 캠페인 행을 하나씩
더하면 ₩207,845,000 입니다. 차이 ₩115,000,000. 화면의 모든 숫자는 행 단위
합계이고 캠페인마다 근거를 볼 수 있습니다. 시트 요약값의 출처는 확인이 필요합니다.

**2. 진행시트 62개 탭 중 24개만 캠페인에 자동으로 붙었습니다**
탭 제목(`오드타입_콘텐츠 제작 협의 인플루언서 리스트_26년 8월 3주차`)과
캠페인명(`[캠페인] 오드타입 26년 8월 3주차`)이 서로 다른 규칙입니다.
나머지 38개는 사람이 연결해야 하며, 그 화면이 1주차 작업에 들어갑니다.

**3. 값이 옆 칸으로 밀린 행이 276건입니다**
송장번호 칸에 주소가 들어있거나, 전화번호 자리에 다른 값이 있습니다.
탭마다 열 개수가 달라서 생긴 문제입니다. 모양이 확실히 어긋난 값은
비워서 내보내고 건수를 대시보드에 표시합니다.

**4. 헤더 표기가 제각각입니다**
송장번호 하나가 `송장번호` · `송장번호(로젠)` · `송장 (롯데)` · `소장번호`(오타)
등 8가지로 적혀 있습니다. 괄호를 떼고 맞추는 선까지만 처리했고,
그 이상은 추측하지 않습니다.

## 개인정보

검수시트에는 실명 · 연락처 · 자택 주소가 그대로 있습니다.
프로토타입에서는 **기본으로 가려서** 보여줍니다.

- 이름 `최•은` — 눌러야 펼쳐집니다
- 연락처 `010-••••-9934` — 뒷자리만
- 주소 — 이름을 펼쳤을 때만

실제 시스템에서는 가리는 수준을 화면이 아니라 **서버에서** 정해야 하고,
누가 언제 열어봤는지 기록이 남아야 합니다. 이 처리는 데이터 구조를 짤 때
넣어야 하며, 나중에는 붙이기 어렵습니다.

## 화면

메뉴는 두 단입니다. 매일 쓰는 영역(홈 · 대시보드 · 세일즈 · 캠페인)이 위,
진입 빈도가 다른 영역(정산 · 관리)이 구분선 아래입니다.

```
홈
대시보드 ─ 대시보드
세일즈   ─ 거래처 · 제안/견적 · 브랜드 페이지 발급 · 랜딩/리드
캠페인   ─ 캠페인 목록 · 모집/선정 · 배송/콘텐츠 · 검수 · 인플루언서 명단
────────
정산
관리 · 설정
```

만들어진 화면은 넷입니다.

| 경로 | 내용 |
|---|---|
| `/` | 홈 — 진행중 캠페인, 업로드 미완, 입금 대기, 연결 대기 진행시트 |
| `/dashboard` | 대시보드 — 매출 · 순이익 · 미수금, 월별 매출, 거래처, 데이터 점검 |
| `/campaigns` | 캠페인 목록 — 상태 · 거래처 필터, 업로드율, 매출, 마진 |
| `/campaigns/[id]` | 캠페인 상세 — 진행 수치, 연결 문서, 참여자 명단 |

나머지 항목은 흐리게 표시되며 아직 화면이 없습니다.
홈이 "지금 뭐가 걸려 있나", 대시보드가 "얼마 벌었나"를 봅니다.

## 만들지 않은 것

프로토타입 범위 밖입니다.

- 로그인 · 권한 (지금은 누구나 전부 봅니다)
- 데이터 수정 (읽기 전용)
- Supabase 연결 (파일에서 읽습니다)
- 브랜드 · 인플루언서 화면

## 디자인

`app/globals.css` 의 토큰은 `siriai-admin.vercel.app` 에서 추출한 값입니다.
`#26221c` 웜블랙 · `#4d4da7` 인디고. 폰트는 Pretendard 와 Inter Tight 를
`public/fonts` 에 직접 넣어 쓰므로 보는 사람 환경을 타지 않습니다.
