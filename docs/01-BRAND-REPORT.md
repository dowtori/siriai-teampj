## 요약

**결론부터: 같은 수준은 됩니다. 일부는 더 잘할 수 있습니다.**

피처링이 채우지 못한 칸(도달·저장·참여)이 있는데, 그건 **인플루언서와 직접 관계가 없어서** 생긴 한계입니다.
SIRIAI는 인플루언서 페이지를 직접 만들기 때문에 그 칸을 채울 수 있습니다. 이게 이 프로젝트에서
피처링을 대체할 근거이자, 대체하지 못하면 굳이 만들 이유가 없는 부분이기도 합니다.

| | 피처링 | 우리가 할 수 있는 것 |
|---|---|---|
| 조회 · 좋아요 · 댓글 | ○ | ○ |
| 공유 · 리포스트 | △ (일부) | △ (일부) |
| **도달 · 저장 · 참여** | **✗ 전부 공란** | **○ — 인플루언서가 연결해주면** |
| 콘텐츠 본문 · 썸네일 | ○ | ○ |
| 프로필 임베드 | ○ | ○ |
| 캠페인 원가 · 마진 | 입력해야 나옴 | **이미 있음** (CPV·CPE 자동) |

## 1. 피처링 보고서에 실제로 무엇이 있나

네 개 탭입니다 — 상세 정보 / 인플루언서 / 콘텐츠 / 리포트.

### 리포트 탭에서 채워진 값

```
총 인플루언서 30명 · 총 콘텐츠 31개
총 조회 332,909 · 좋아요 760 · 댓글 314 · 공유 24 · 리포스트 28
총 인게이지먼트 1,074 · 전체 ER 1.73%
```

### 비어 있는 값 — 여기가 핵심

```
총 저장 수      -
총 참여 수      -
총 도달 수      -
총 인용 수      -
총 제안 단가    -
총 집행 비용    -
전체 CPV        -
전체 CPE        -
```

앞의 넷은 **인스타그램이 공개하지 않는 지표**입니다. 게시자 본인만 볼 수 있습니다.
뒤의 넷은 **비용 데이터가 없어서** 계산이 안 된 것입니다. 우리는 원고료와 매출을 이미 들고 있으니
이 칸들은 바로 채워집니다.

### 그 밖에 관찰된 것

- 콘텐츠마다 `업데이트 일시`가 붙고 전부 같은 분(`2026.08.12 10:39`)입니다 → **주기적 일괄 수집** 방식
- 인플루언서 한 명은 카테고리가 `(업데이트 예정)` → 프로필 보강이 **비동기 큐**로 돌아감
- 캠페인당 `30명/500` 상한 표기 → 요금제 제한
- 콘텐츠 본문 전문을 수집해 그대로 보여줌
- 카테고리(뷰티·패션·건강가전)는 자동 분류로 붙음

참고로 좋아요 760이 조회 332,909 대비 0.23%로 비정상적으로 낮습니다. 릴스 조회수는 잡혔지만
좋아요·댓글은 일부만 수집된 것으로 보입니다. **넘어야 할 기준이 생각보다 높지 않다**는 뜻입니다.

## 2. 플랫폼별로 무엇이 가능한가

### 유튜브 — 전부 됩니다

**YouTube Data API v3.** 공식·무료(일 10,000 유닛), 인증 불필요.

```
videos.list?part=snippet,statistics&id={영상ID}
  → viewCount · likeCount · commentCount · title · publishedAt · thumbnails
channels.list?part=statistics,snippet&id={채널ID}
  → subscriberCount · videoCount · 프로필 이미지
```

영상 하나 조회에 1유닛. 콘텐츠 1,000개를 하루 10번 갱신해도 여유롭습니다.
**여기는 고민할 게 없습니다.**

### 인스타그램 — 두 갈래로 나뉩니다

2024년 12월 Basic Display API가 완전히 종료됐고, 개인 계정은 API로 접근할 수 없습니다.
비즈니스·크리에이터 계정만 대상입니다.

**(A) 크리에이터 동의 없이 — 공개 지표만**

`Business Discovery` 엔드포인트. 우리 쪽 인스타그램 프로 계정과 페이스북 앱이 필요합니다.

```
GET /{our-ig-id}?fields=business_discovery.username(대상){
      followers_count, media_count,
      media{ like_count, comments_count, caption, permalink, timestamp, media_type }
    }
```

얻는 것 — 팔로워 수, 게시물 수, 게시물별 좋아요·댓글·본문·링크·업로드 시각.
**못 얻는 것** — 도달, 저장, 공유, 프로필 방문.
릴스 조회수는 정책이 자주 바뀌어 **실측 검증이 필요합니다** (아래 3-1).

**(B) 크리에이터가 연결해주면 — 전부**

인플루언서 페이지에 **"인스타그램 연결"** 버튼을 둡니다.
크리에이터가 한 번 누르면(Instagram Login for Business) 그 뒤로는 자동입니다.

```
GET /{media-id}/insights?metric=reach,saved,shares,total_interactions,plays
```

**피처링이 `-`로 비워둔 칸이 여기서 채워집니다.**
피처링은 인플루언서와 계약 관계가 없어서 이걸 요청할 수 없습니다. 우리는 할 수 있습니다.

### 틱톡 — 가장 어렵습니다

- Display API는 사용자 OAuth 필요 → 인스타그램 (B)와 같은 방식으로만 가능
- Research API는 학술 목적으로 승인 절차가 까다로움
- 크롤링은 약관 위반

현재 틱톡 캠페인 비중이 낮으니(원본 20,347건 중 3,212건, 대부분 일본) **후순위로 미뤄도 됩니다.**
필요해지면 인플루언서 연결 방식으로 붙입니다.

### 네이버 블로그

RSS와 공개 페이지로 제목·본문·작성일은 수집 가능. 조회수는 공개되는 경우와 아닌 경우가 섞입니다.

## 3. 실행 방안 — 3단계

### 0단계 · 승인도 개발도 거의 필요 없는 것 — **이미 붙였습니다**

**콘텐츠 임베드는 API 키도 앱 심사도 필요 없습니다.**

```
https://www.instagram.com/{p|reel}/{shortcode}/embed/
```

이 주소를 iframe 에 넣으면 끝입니다. 공개 게시물이면 그대로 렌더됩니다.
(앞서 oEmbed 로 적었으나, oEmbed 는 `oembed_read` 앱 심사가 필요합니다. iframe 방식은 필요 없습니다.)

우리 데이터에 **콘텐츠 링크가 이미 524건** 있고 그중 512건에서 shortcode 가 뽑힙니다.
전부 인스타그램입니다 — 릴스 434 · 피드 90.

| | |
|---|---|
| 인스타 | `/{p\|reel}/{code}/embed/` iframe · 승인 불필요 |
| 유튜브 | `youtube.com/embed/{id}` iframe · 승인 불필요 |
| 틱톡 | `tiktok.com/embed/v2/{id}` iframe · 승인 불필요 |

**이것만으로도 브랜드 페이지에 실제 게시물이 박힙니다.** 지표가 하나도 없어도
"우리 캠페인 콘텐츠가 이렇게 나왔다"는 보여줄 수 있습니다. 이게 기본안의 핵심입니다.

### 1단계 · 지금 바로 (개발 3–4일)

크리에이터 동의가 필요 없는 지표를 채웁니다.

| 항목 | 방법 |
|---|---|
| 유튜브 지표 | Data API v3 · 자동 |
| 인스타 팔로워 · 좋아요 · 댓글 | Business Discovery · 자동 |
| 원가 · 매출 · CPV · CPE | **이미 우리 데이터에 있음** |
| 도달 · 저장 | 인플루언서 제출 (지금 정산자료 받는 흐름에 얹기) |

0단계 + 1단계면 **피처링과 같은 화면이 나옵니다.** CPV·CPE는 오히려 우리가 낫습니다.

### 2단계 · 인플루언서 연결 (개발 1주 + 심사)

인플루언서 페이지에 계정 연결 버튼을 답니다.

```
[내 인스타그램 연결하기]
  → 연결하면 캠페인 성과가 자동으로 반영됩니다.
     매번 인사이트 화면을 캡처해서 보내지 않아도 됩니다.
```

크리에이터에게도 이득입니다 — 지금은 정산 때마다 인사이트를 캡처해 슬랙으로 보내야 합니다.
연결률이 절반만 나와도 **피처링이 못 채우는 칸을 절반 채웁니다.**

> Meta 앱 심사가 필요합니다. `instagram_business_manage_insights` 권한 승인에
> 통상 1–3주. 알림톡 심사처럼 **미리 신청해두어야 합니다.**

### 3단계 · 자동 수집 파이프라인 (개발 3–4일)

피처링처럼 주기적으로 돌립니다.

```
매일 새벽 1회 + 캠페인 종료 직후 집중 수집
  → 콘텐츠별 지표 스냅샷 저장 (시계열)
  → 업로드 후 24h / 72h / 7d / 30d 시점 성과 비교
```

시계열로 쌓으면 **피처링에 없는 것**이 생깁니다 — "이 인플루언서는 업로드 3일 뒤에도
조회가 계속 오른다" 같은 판단. 재섭외 기준이 됩니다.

### 검증이 필요한 두 가지 (1일 스파이크)

1. **인스타 릴스 조회수**를 Business Discovery로 받을 수 있는가 — 정책이 자주 바뀌어 실측 필요
2. **연결한 크리에이터**에게서 실제로 어느 지표까지 오는가

이 둘만 확인하면 나머지는 계획대로 갑니다. 실제 캠페인 계정 하나로 붙여보면 반나절이면 답이 나옵니다.

## 4. 프로필 · 콘텐츠 임베드

| 대상 | 방법 | 비고 |
|---|---|---|
| 인스타 게시물 | oEmbed | 공식·무료. 실제 게시물이 그대로 박힘 |
| 유튜브 영상 | iframe | 제약 없음 |
| 틱톡 영상 | oEmbed | 지표는 없지만 임베드는 됨 |
| **인플루언서 프로필** | 자체 카드 | 인스타가 프로필 임베드를 지원하지 않음 |

프로필 이미지는 인스타 CDN 주소가 만료되므로 **우리 쪽에 캐싱**해야 합니다.
자체 카드로 만들면 팔로워·ER·과거 협업 이력까지 함께 보여줄 수 있어 오히려 낫습니다.

```
┌──────────────────────────────┐
│  ◯  beureyu                   │
│     수비니 · 뷰티 · 패션        │
│     94,730 팔로워             │
│  ─────────────────────────    │
│  이번 캠페인   88,366 조회      │
│  함께한 횟수   3회             │
└──────────────────────────────┘
```

## 6. 정리 — 무엇을 언제

| 0 | API 검증 스파이크 | 1일 | — |

## 7. 결정이 필요한 것

1. **피처링을 계속 쓸지** — 병행하다 넘어올지, 처음부터 자체로 갈지. 지금 피처링에 쌓인
   과거 캠페인 데이터를 가져올 수 있는지도 확인이 필요합니다.
2. **인플루언서 계정 연결을 필수로 할지** — 선정 조건으로 걸면 연결률이 올라가지만 진입 장벽이 됩니다.
3. **브랜드 검토 권한 범위** — 브랜드가 제외한 인원을 우리가 다시 넣을 수 있는지, 최종 결정권이 어디인지.
4. **보고서 공개 수준** — 원고료·마진을 브랜드에 보여줄지. 지금 브랜드 페이지는 전부 가리고 있습니다.
